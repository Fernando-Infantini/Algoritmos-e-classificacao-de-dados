# 📘 Algoritmos e Classificação de Dados — Códigos em Java

Este repositório contém todos os códigos desenvolvidos durante a disciplina de **Algoritmos e Classificação de Dados**, organizados por projeto/pasta, conforme solicitado pelo professor.

Cada pasta corresponde a um mini-projeto, exercício ou estrutura de dados implementada em Java ao longo da disciplina.

---

## 📂 Estrutura do Repositório

Cada pasta possui um código/projeto em java
Cada pasta possui um arquivo `info.txt` com explicações detalhadas do projeto.
Para testar compile todos os códigos com 'javac' e execute o Main com o comando java, casos especiais serão apontados nos info.txt

## 🔹 Mercado

### 📌 Descrição:
Criar um sistema de mercado capaz de gerir um estoque e montar as notas das compras realizadas por clientes

### 📘 Conteúdo:
- Estruturas utilizadas: Listas encadeadas, enum, herança e polimorfismo, além de classes para abstração de produtos, clientes e compras.
- Problema resolvido: Organização e controle de um sistema de mercado, permitindo gerenciar produtos disponíveis e gerar a nota das compras realizadas pelos clientes.

---

## 🔹 Resistencia

### 📌 Descrição:
Gerar um código capaz de resolver a resistência equivalente em circuitos em série e paralelo

### 📘 Conteúdo:
- Tema abordado: Cálculo da resistência elétrica equivalente em circuitos formados por resistores em série e em paralelo.
- Algoritmo principal: Aplicação direta das fórmulas de associação de resistores, soma das resistências em série e cálculo do inverso da soma dos inversos em paralelo.

# 🎵 Spotyfom 2.0 - Sistema de Gerenciamento de Músicas em Java

## 📌 Descrição
O **Spotyfom** é um sistema em Java que simula um tocador de músicas.  
Ele permite cadastrar músicas e buscar conteúdos.
Foi feito com base no código original em C disponível em: https://github.com/Fernando-Infantini/Spotyfom

O projeto foi desenvolvido com foco em estruturas de dados e árvoreB.

---

## ⚙ Funcionalidades
✅ Leitura de músicas a partir de arquivo  
✅ Busca por título, artista e código    
✅ Sistema sem travamentos por entrada inválida  
✅ Vizualização do sistema por meio de árvores B

---

## 📂 Estrutura do Projeto

| Arquivo | Função |
|----------|--------|
| `Spotyfom.java` | Lógica do sistema |
| `Musica.java` | Modelo da música |
|`NoArvoreB.java` | Estrutura do nó da arvore |
|`ArvoreB.java` | Estrutura da raiz da arvore |
| `info.txt` | Documentação técnica |
| `*.txt` | Arquivos com musicas para entrada |

---

## 📄 Formato do Arquivo de Entrada

O arquivo de músicas deve seguir o seguinte formato:

numero de musicas\lixo
artista;codigo;titulo;letra;lixo
